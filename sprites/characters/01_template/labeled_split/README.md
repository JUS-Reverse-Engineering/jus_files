# Reviewed character art

Use these categories: `generics`, `hitstun`, `attacks_light`, `attacks_heavy`, `attacks_special`, `supports`, `panels`, `taunt`, `misc`.

`art.json` records source hashes, explicit frame order, components and placements, facing, branch relationships and unresolved questions. Copy the common framework, then fill it from reviewed source art. Empty folders do not establish coverage.

Retain `*_ORIGINAL` images as references for rearranged strips. Preserve authored left/right differences and shared effects. Frame PNGs preserve native pixels and an explicit origin; strips are review conveniences. Do not guess playback durations from strip spacing.

The authoring standard and commands live in the parent source repository at `docs/rebuild/cast-art/README.md`. The runtime export contract remains `docs/rebuild/normalized-library/README.md`.
