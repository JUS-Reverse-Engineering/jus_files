# Reviewed cast art

57 sheet packages represent 56 guide characters. Each package retains its
original source and old `split/` proposals beside categorized `labeled_split/`
art. [Open the sprite browser](../ART_REVIEW.html) to filter by character,
category and source, preview the first pose, or inspect a complete strip.

The shared categories are generics, hitstun, attacks_light, attacks_heavy,
attacks_special, supports, panels, taunt and misc. Package READMEs explain
local repairs, form distinctions and unresolved compositions. `art.json` keeps
source hashes, explicit pose order, native origins, ownership and review evidence.

These are reviewed authoring candidates. Distinct-pose strips do not certify
playback timing or gameplay selection. A source reference does not imply
complete pixel reconciliation, and native-only form candidates remain labeled.
