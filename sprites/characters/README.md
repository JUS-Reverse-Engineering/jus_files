# Reviewed cast art

81 authoring packages contain 69 fighter entries and 12 shared character containers.
The 24 form packages have separate READMEs and manifests. The 57 original
source sheets represent 56 guide characters; Seiya has two source sheets.

The cast now contains 9,705 categorized assets and 35,312 normalized frame PNGs
in [81 frame libraries](../normalized/README.md).

Each package retains source provenance and categorized art. Shared containers
hold supports, panels and source-only pieces; their fighter forms are linked
separately below. Counts come from the current `art.json` manifests.

The categories are generics, hitstun, attacks_light, attacks_heavy,
attacks_special, supports, panels, taunt and misc. Visual source review and
native pixel verification do not certify runtime timing or conditional
composition. Native-only form candidates retain that status in their manifests.
